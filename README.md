# Чат через GREEN-API

Тестовое задание на позицию «Фронтенд разработчик React»: простой веб-чат для отправки
и получения текстовых сообщений через сервис GREEN-API. Интерфейс повторяет
базовую раскладку web.max.ru: слева список чатов, справа переписка.

## Что умеет

- вход по данным инстанса GREEN-API: `idInstance`, `apiTokenInstance` (и `apiUrl`, если у
  инстанса свой адрес API);
- создание чата по номеру телефона получателя;
- отправка текстового сообщения методом `SendMessage`;
- получение входящих через очередь уведомлений: `ReceiveNotification` → `DeleteNotification`
  (длинный опрос, `receiveTimeout` 5 секунд);
- чаты и история хранятся в браузере, после перезагрузки страницы остаются.

Только текстовые сообщения, без файлов, групп и статусов прочтения, как и требовалось.

## Запуск локально

Нужен Node.js 18 или новее.

```bash
npm install
npm run dev
```

Открыть адрес, который напишет Vite (обычно http://localhost:5173).

Сборка для продакшена:

```bash
npm run build
npm run preview
```

Готовые файлы лежат в `dist/`, это статика, её можно положить на любой хостинг.

## Как проверить

1. В личном кабинете GREEN-API создать инстанс, авторизовать его (QR-код), скопировать
   `idInstance` и `apiTokenInstance`. Если в кабинете указан отдельный `apiUrl` вида
   `https://7103.api.green-api.com`, вписать его в поле `apiUrl`.
2. Войти в приложение. При входе проверяется `getStateInstance` (инстанс должен быть
   `authorized`) и включается `incomingWebhook`, чтобы входящие копились в очереди.
3. Ввести номер получателя (только цифры, с кодом страны), создать чат, отправить текст.
4. Получатель отвечает в мессенджере, ответ появляется в чате в течение нескольких секунд.

## Структура

- `src/api.ts` – обёртка над HTTP API: `sendMessage`, `receiveNotification`,
  `deleteNotification`, `getStateInstance`, `getSettings`/`setSettings`;
- `src/App.tsx` – экран входа, список чатов, переписка, цикл опроса уведомлений;
- `src/App.css` – оформление.

Без сторонних библиотек, кроме React и Vite.
